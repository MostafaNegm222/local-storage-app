# Local Storage Control App

## 1. Description

A small app with an interactive interface to manage the browser's local storage: add, display and delete keys and their values.

## 2. Technologies and Versions

- HTML5, CSS3, vanilla JavaScript (no build step)

## 3. Requirements and Dependencies

- A modern web browser
- No packages to install

## 4. Installation and Run Steps

```bash
git clone https://github.com/MostafaNegm222/local-storage-app.git
cd local-storage-app
```

Open `index.html` in a browser, or serve the folder with any static server.

## 5. Environment Variables

None required.

## 6. Usage and Main Features

- **Add key-value pair**: store a new entry in local storage.
- **Show a specific key**: retrieve and display one value.
- **Show all keys**: list everything currently stored.
- **Delete a specific key** or **delete all keys**.
- Implemented in plain JavaScript functions (`addItem()`, `checkItem()`, `showItems()`, `deleteItem()`, `deleteAll()`).
